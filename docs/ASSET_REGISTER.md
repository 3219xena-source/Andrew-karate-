A deliberately simplified, recognisable illustration of Tasmania drawn in a 0–100 coordinate space.

**It is not survey data.** It is not traced from, derived from, or generated using satellite imagery,

## Replacement checklist before production

1. **Team emblems** — six commissioned club marks; set them in `src/data/teams.ts` and extend
   `Emblem.tsx` to render an image when one is configured.
2. **Fighter portraits** — set `portraitAsset` on each fighter record. No component changes needed.
3. **Character art** — per-fighter sprite sheets or skeletal animation; add a new `animation.set`
   value and a renderer that handles it.
4. **Voice lines** — record the declared clips, set `voice.enabled: true`, and add playback to the
   audio manager.
5. **Recorded score and foley** *(optional)* — if the procedural audio is replaced with recordings,
   this register must be updated with the source, licence and attribution requirement of every file
   added, and any required attribution surfaced in a credits screen.

Rule for whoever does this work: **no asset enters the repository without a row in this table.**
